# Game Input Lab: engine packages

Reference implementations for Unity, Godot and Unreal of the Game Input Lab app. They run the same stick response, smoothing, touch handling, layouts, tilt and vibration rules as the app, and are checked against the same test vectors, so what you tuned on a phone behaves the same in your game.

Version 0.2.0. The code the app exports asks for this version or newer.

| Engine | Folder | Install |
|---|---|---|
| Unity 2022.3+ | `engines/unity/com.gameinputlab.input` | Package Manager ▸ + ▸ Add package from git URL: `https://github.com/lmj-labs/game-input-lab-engines.git?path=/engines/unity/com.gameinputlab.input` |
| Godot 4.2+ | `engines/godot/addons/game_input_lab` | Copy the folder into your project's `addons` folder |
| Unreal 5.1+ | `engines/unreal/GameInputLab` | Copy the folder into your project's `Plugins` folder |

Each package has its own README with usage. `engines/fixtures/joystick-vectors.json` is the shared test data; it is generated by the app, so do not edit it.
